\begin{enumerate}[series=q, label={Question \arabic*:}, leftmargin=*, align=left]
  \item How much total time do you estimate the digital scholarship application process through ScholarPath AdDU would require? (This includes the time spent discovering a scholarship, verifying your eligibility, uploading documents to the Document Vault, and submitting an application.)
  \begin{itemize}[leftmargin=*]
    \item Question Type: Multiple Choice
    \item Options:
    \begin{itemize}[leftmargin=*]
      \item Less than 1 day
      \item 1 -- 3 days
      \item 4 -- 7 days
      \item 1 -- 2 weeks
      \item More than 2 weeks
    \end{itemize}
  \end{itemize}
\end{enumerate}

\section{Component 2: Perceived Effort Scale}

The following questions assess the difficulty of specific tasks while using ScholarPath AdDU. Please use the same scale you applied in the pre-study survey for direct comparison.

\begin{enumerate}[resume=q, label={Question \arabic*:}, leftmargin=*, align=left]
  \item On a scale of 1 to 5, please rate how easy or difficult it was to complete each of the following steps using ScholarPath AdDU:
  \begin{itemize}[leftmargin=*]
    \item Question Type: Likert Grid (5-point scale)
    \item Scale Columns:
    \begin{itemize}[leftmargin=*]
      \item 1 - Very Easy
      \item 2 - Easy
      \item 3 - Neutral
      \item 4 - Difficult
      \item 5 - Very Difficult
    \end{itemize}
    \item Row Sub-tasks:
    \begin{enumerate}[label=\arabic*., leftmargin=*]
      \item Finding out which specific scholarships or grants you were eligible for using the centralized scholarship repository.
      \item Determining whether you specifically met all eligibility criteria using the results produced by the Smart Eligibility Checker.
      \item Uploading and managing the required documents through the Document Vault.
      \item Submitting a completed application digitally through the platform.
      \item Tracking the status of your application through the student dashboard.
      \item Keeping track of multiple scholarship deadlines using the automated notification system.
    \end{enumerate}
  \end{itemize}
\end{enumerate}

\section{Component 3: System Feature Effectiveness}

This section assesses the perceived effectiveness of ScholarPath AdDU's core features in addressing specific problems identified in the manual process.

\begin{enumerate}[resume=q, label={Question \arabic*:}, leftmargin=*, align=left]
  \item Do you believe the Smart Eligibility Checker would effectively prevent you from applying to scholarships for which you do not qualify?
  \begin{itemize}[leftmargin=*]
    \item Question Type: Multiple Choice
    \item Options:
    \begin{itemize}[leftmargin=*]
      \item Yes, I believe it would prevent mismatched applications
      \item Partially: it would help, but I might still need to verify manually
      \item No, I do not think it would reliably prevent ineligible applications
      \item Unsure
    \end{itemize}
  \end{itemize}
  \item To what extent do you believe the automated deadline notification and alert system in ScholarPath AdDU would make it easier to stay aware of upcoming application deadlines?
  \begin{itemize}[leftmargin=*]
    \item Question Type: Likert Scale
    \item Options:
    \begin{itemize}[leftmargin=*]
      \item 5 - Strongly Agree
      \item 4 - Agree
      \item 3 - Neutral
      \item 2 - Disagree
      \item 1 - Strongly Disagree
    \end{itemize}
  \end{itemize}
\end{enumerate}
