\chapter{Pre-Study Student Problem Validation Survey}
\label{app:pre-survey}

Question 1: Have you ever applied for a scholarship or financial aid at Ateneo de Davao University using the manual/traditional application process?

\begin{itemize}
  \item Question Type: Multiple Choice
  \item Options:
  \begin{itemize}
    \item Yes (Continue to next section)
    \item No (Submit form - they are not your target respondents) Component 1 - Perceived Time-on-Process Please recall your most recent experience applying for a scholarship at AdDU using the traditional, paper-based process. Question 2: How much total time did you spend navigating the entire manual application process? (This includes the time spent discovering the scholarship, gathering requirements, routing forms like Form 230-SCH, and physically submitting the documents).
  \end{itemize}
  \item Question Type: Multiple Choice
  \item Options:
  \begin{itemize}
    \item Less than 1 day
    \item 1 -- 3 days
    \item 4 -- 7 days
    \item 1 -- 2 weeks
    \item More than 2 weeks Component 2 - Perceived Effort Scale The following questions assess the difficulty of specific tasks during the manual application process. Question 3: On a scale of 1 to 5, please rate how easy or difficult it was to complete the following application steps:
  \end{itemize}
  \item Question Type : Likert Grid (5-point scale)
  \item Scale Columns :
  \begin{itemize}
    \item 1 - Very Easy
    \item 2 - Easy
    \item 3 - Neutral
    \item 4 - Difficult
    \item 5 - Very Difficult
  \end{itemize}
  \item Row Sub-tasks : 1. Finding out which specific scholarships or grants you were eligible for. 2. Determining whether you specifically met all eligibility criteria --- such as QPI requirement, household income ceiling, and degree program restriction --- for a scholarship before submitting an application. 3. Gathering, printing, and preparing the required physical documents. 4. Physically submitting the completed application package to the respective offices. 5. Tracking the status of your application after submission. 6. Keeping track of multiple scholarship deadlines simultaneously throughout the application period. Component 3: Application Accuracy and Deadline History This section helps establish how often errors and missed deadlines occurred under the manual process. Question 4: Have you ever submitted a scholarship application and later discovered that you did not meet the eligibility requirements for that scholarship?
  \item Question Type: Multiple Choice
  \item Options:
  \begin{itemize}
    \item Yes
    \item No
    \item I am not sure Question 5: (Displayed only if ``Yes'' is selected in Question 4.) Approximately how many times did this occur?
  \end{itemize}
  \item Question Type: Multiple Choice
  \item Options:
  \begin{itemize}
    \item Once
    \item 2 -- 3 times
    \item 4 or more times Question 6: Have you ever missed a scholarship application deadline while using the manual application process?
  \end{itemize}
  \item Question Type: Multiple Choice
  \item Options:
  \begin{itemize}
    \item Yes
    \item No Question 7: (Displayed only if ``Yes'' is selected in Question 6.) What was the primary reason you missed that deadline?
  \end{itemize}
  \item Question Type: Multiple Choice
  \item Options:
  \begin{itemize}
    \item I was unaware that the deadline existed or had passed
    \item I did not have enough time to prepare the required physical documents
    \item I forgot to follow up on the application after initial discovery
    \item Other (Please specify)
  \end{itemize}
\end{itemize}
