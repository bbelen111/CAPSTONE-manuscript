  \item How much total time did you spend navigating the entire manual application process? (This includes the time spent discovering the scholarship, gathering requirements, routing forms like Form 230-SCH, and physically submitting the documents.)

    \item Question Type: Multiple Choice
    \item Options:
    \begin{itemize}[leftmargin=*]

      \item More than 2 weeks

  \end{itemize}

\section{Component 2 - Perceived Effort Scale}

The following questions assess the difficulty of specific tasks during the manual application process.

\begin{enumerate}[resume=q, label={Question \arabic*:}, leftmargin=*, align=left]
  \item On a scale of 1 to 5, please rate how easy or difficult it was to complete the following application steps:
  \begin{itemize}[leftmargin=*]
    \item Question Type: Likert Grid (5-point scale)
    \item Scale Columns:
    \begin{itemize}[leftmargin=*]
      \item 1 - Very Easy
      \item 2 - Easy
      \item 3 - Neutral
      \item 4 - Difficult
      \item 5 - Very Difficult
    \end{itemize}
    \item Row Sub-tasks:
    \begin{enumerate}[label=\arabic*., leftmargin=*]
      \item Finding out which specific scholarships or grants you were eligible for.
      \item Determining whether you specifically met all eligibility criteria (such as QPI requirement, household income ceiling, and degree program restriction) for a scholarship before submitting an application.
      \item Gathering, printing, and preparing the required physical documents.
      \item Physically submitting the completed application package to the respective offices.
      \item Tracking the status of your application after submission.
      \item Keeping track of multiple scholarship deadlines simultaneously throughout the application period.
    \end{enumerate}
  \end{itemize}
\end{enumerate}
